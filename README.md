# GeneSite

GeneSite is a content-first static publication built with Astro, TypeScript,
Markdown, MDX, and one Content Layer collection named `writings`.

Phase 1 implements the content contract, validation, representative development
fixtures, and minimal inspection routes. Product and architecture decisions live
in [`docs/`](./docs/INDEX.md).

## Commands

```sh
npm install
npm run verify
```

Use `npm run dev` for local inspection. Node 24 is the repository-supported
major version.
